- [ ] token refresh/rotation, revoked connection וניתוק פועלים ללא חשיפת סודות.

## יצירת ישיבה

- [ ] כפתור השליחה מציג מוזמנים אמיתיים ושולח פעם אחת; duplicate click/timeout/retry אינם יוצרים כפילויות.
- [ ] timezone ושינוי שעון ישראל נבדקו, גם תאריך שינוי שעה; התחלה/סיום תקינים.
- [ ] Google+Meet ו-Microsoft+Teams נבדקו בחשבונות המתאימים; יכולת שלא נבדקה אינה מוצגת כפעילה.
- [ ] Zoom+journal flow מטפל בכשל אחרי יצירת קישור ולפני אירוע בלי Zoom כפול.
- [ ] עדכון זמן וביטול פגישה לא יוצרים ישיבה חדשה; הודעות ספק ונתוני VITAS עקביים.
- [ ] invitees אינם מוצגים כ-attendees בלי ראיה; חשבון Microsoft אישי אינו מזוהה אוטומטית כ-Teams ארגוני.

## חומרים ותמלול
- [ ] scheduled/ended אינם הוכחה להקלטה; unavailable, processing ו-permission_required נבדלים.
- [ ] תמלול עברית נבדק על דוגמת ישיבה אמיתית מורשית, כולל שמות, מספרים, מונחי נדל״ן ודוברים.
- [ ] חשבון ללא recording entitlement מקבל מסלול העלאה ידנית ולא כפתור מקליט מדומה.
- [ ] webhook כפול/מאוחר/out-of-order אינו יוצר jobs כפולים; חתימות, replay limits ו-mapping נבדקים.
- [ ] חומר שבעליו מחק/שלל הרשאה אינו מוצג כזמין; timestamps ומקורות נשמרים.
- [ ] upload גדול/פורמט לא תקין, URL פנימי/redirect מסוכן, קובץ חסר ותמלול ריק מטופלים.
