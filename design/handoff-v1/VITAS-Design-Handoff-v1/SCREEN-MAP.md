# מפת מסכי הנדל״ן

| מסך | סדר תוכן לשימור | סטטוס בחבילה |
|---|---|---|
| הכל | KPI, משפך, קמפיינים, מגדר, גיל, מודעות Facebook, מודעות Google | סקיצה מאושרת + פרימיטיבים + הרכבת React |
| CRM — מקורות הגעה | KPI, משפך עם סינון מקור, טבלה, גרף | מיפוי בלבד; סקיצה ייעודית בהמשך |
| CRM — זמני תגובה | KPI, התפלגות זמן, יום בשבוע, יום מבוקש לפגישה, שעות תיאום ולידים, שעות אין מענה, אנשי מכירות, מקורות איטיים | מיפוי בלבד; גרפים נשארים ב-Chart.js |
| CRM — התנגדויות | גרף התנגדויות + פירוט/פתיחת לידים הקיימים | מיפוי בלבד |
| CRM — יישובים | 10 יישובים עם סינון לידים/פגישות/חוזים, מצב דיור, סוג נכס | מיפוי בלבד |
| CRM — פגישות שבוצעו | טבלת פגישות מלאה | ReportTable ניתן לשימוש; מיפוי שדות נדרש |
| Facebook | המבנה הקיים ונתוני הפלטפורמה בלבד | reuse לרכיבים; QA לסינון נדרש |
| Google | המבנה הקיים ונתוני Google; לשמור קבוצות נכסים/קריאייטיב קיימים | reuse לרכיבים; renderer ייעודי למודעות טקסט/וידאו |
| המלצות חכמות | חדש/בתוכנית, בעלי תפקידים, פעולות קיימות | בטא; סקיצה ושינוי לוגיקת המלצות מחוץ לפיילוט |

גישת לקוח משתמשת באותם רכיבי תצוגה בלי פעולות מנהל ובלי גישה ללקוחות אחרים. אין לעצב ״אפליקציה נוספת״ בשביל הלקוח.

KLOSS ו-BCure הם תבניות עסקיות נפרדות. רכיבים משותפים אפשר לשתף בעתיד; אין להחליף שלבי מכירה/הזדמנות/הצעה/רכישה בפגישות/הרשמות/חוזים.
