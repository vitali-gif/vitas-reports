# עיצוב מחדש של הדשבורד — ענף `redesign`

עובדים כאן, לא על `main`. כל push לענף מקבל מ-Vercel כתובת Preview משלו (אותו Supabase, אותם
נתונים והרשאות, אבל בלי לגעת ב-https://reports.vitas.co.il). `main` נשאר הגרסה החיה עד שוויטלי
מאשר למזג.

## מה שמים כאן

- `design/<screen>/sketch.png` — הסקיצה (למשל `design/all/sketch.png`, `design/crm-response-times/sketch.png`)
- `design/<screen>/spec.md` — המפרט: סדר אלמנטים, מידות, כותרות, פילטרים, מה נפתח בלחיצה
- `design/tokens.md` — השפה העיצובית המשותפת (פונטים, צבעים, ריווחים, כרטיסים, כפתורים, טבלאות, גרפים)
- `design/components/` — רכיבים/CSS שהגיעו מהחבילה, לפני שהם משולבים בקוד

## סדר העבודה (שהוסכם 17.9.2026)

1. מסך "הכל" קודם: מיישמים, מצלמים את ה-Preview, משווים לסקיצה, מתקנים פערים.
2. אותם רכיבים לשאר המסכים: 5 תתי-CRM, פייסבוק, גוגל, המלצות חכמות.
3. מפרט הבדלים לקוח מול אדמין. 4. התאמות KLOSS / BCure.

הלוגיקה והחישובים לא נוגעים — רק שכבת התצוגה. מסכים חדשים נבנים כרכיבים נפרדים
ב-`app/components/` ומחוברים טאב אחרי טאב.
