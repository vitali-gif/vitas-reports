# בדיקות לפני מסירה

עברו: קומפילציית JSX לכל הרכיבים ודוגמת השילוב; פענוח שני קובצי CSS; רינדור React בצד שרת של ארבעת הכרטיסים וחמשת אזורי הגרפים ושתי הטבלאות; מצבי loading/missing/empty/error עם model=null; תצוגת אפס לעומת חסר, דחיית ערכים שליליים/NaN/Infinity בגרף; התאמת סכומי דוגמת הפיתוח; היעדר style inline בקוד JSX.

לא בוצעו בחבילה: שילוב במאגר VITAS, build של הפרויקט האמיתי, בדיקה חזותית בדפדפן, הרצת Chart.js על canvas, בדיקות הרשאות ונתוני ייצור. יש להשלים לפי ACCEPTANCE.md. הסקיצה היא רפרנס חזותי בלבד; גרפיה אינם תוצאת הקוד המצורף ומספריה אינם מקור אמת.
